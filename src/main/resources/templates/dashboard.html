1. Zero-Trust Mesh Relay

Intermediary phones pass encrypted packets without knowing sender, receiver, amount, or PIN. Uses hybrid RSA-2048 OAEP to wrap an ephemeral AES-256-GCM symmetric session key. Tamper attempts immediately break the GCM auth tag.

2. Idempotency & Storm Defense

In a mesh gossip network, dozens of phones may hit cellular range at once and upload identical copies. The backend hashes ciphertext with SHA-256 and executes an atomic compare-and-set claim. Exactly one settles; all duplicates drop harmlessly.

3. Anti-Replay & Freshness Window

Every transaction carries a signed timestamp and a cryptographically secure random UUID nonce. The server enforces a maximum age window (24 hours). Expired or replayed packets are rejected before ever touching the ledger.
